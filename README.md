# Adventure Time for Hytale

Swords from *Adventure Time* for Hytale, by Dackoro.

- Finn Sword
- Scarlet Sword
- Night Sword
- Tree Sword
- Grass Sword: cursed. It never breaks, can't be dropped, and always comes back to you.

Each sword has its own sounds, swing trails and a signature effect.

## Install

- Download it from CurseForge: https://www.curseforge.com/projects/1448331
- Or build it yourself with JDK 25: `.\gradlew build`, then copy `build\libs\*.jar` into your Hytale `Mods` folder.

The Grass Sword's curse is a small Java plugin. Everything else is content: JSON, models, textures and sounds.
